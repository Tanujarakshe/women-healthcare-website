# 🌸 Women's Healthcare & Safety Website

## 📌 Project Overview

**Women's Healthcare & Safety** is a simple and informative web-based project designed to provide women with essential information related to **healthcare, menstrual health, personal safety, emergency contacts, doctors, and awareness resources**.

The website aims to empower women by making important healthcare and safety information easily accessible through a clean and user-friendly interface.

---

## ✨ Features

* 🔐 **Login Section**

  * Username and password input fields.
  * Basic required-field validation.

* 🏥 **Women's Healthcare**

  * General healthcare tips.
  * Information about regular check-ups, healthy diet, exercise, mental health, reproductive health, and vaccination.

* 🩸 **Menstrual Cycle Tracking Tips**

  * Tips for tracking periods.
  * Recording symptoms and flow intensity.
  * Guidance on when to consult a healthcare professional.

* 🛡️ **Safety Tips**

  * Personal safety guidelines.
  * Emergency contact preparation.
  * Location sharing and safety app recommendations.
  * Self-defense awareness.

* 🚨 **Emergency Contact Numbers**

  * Women's helpline.
  * Police.
  * Ambulance.
  * Fire department.
  * Cyber crime support.
  * Mental health support.

* 👩‍⚕️ **Doctors Information**

  * Sample gynecologist, psychologist, and general physician information.

* 🎥 **Awareness Videos**

  * Supports MP4 awareness videos using the HTML5 `<video>` element.

* 📩 **Contact Us**

  * Name, email, and message form.

* 💬 **Welcome Alert**

  * Displays a welcome message when the website loads.

* 📱 **Responsive Design**

  * Uses the viewport meta tag for better compatibility with different screen sizes.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/womens-healthcare-safety.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd womens-healthcare-safety
```

### 3. Run the Website

Open `index.html` in any modern web browser.

You can also use **Visual Studio Code** with the **Live Server** extension.
